FIVEMORE

Five minutes. Five more minutes. One more run.

A vertical zombie survivors-like for mobile browsers. Move with one finger, weapons fire automatically, level up and pick 1 of 3 upgrade cards.

	•	Platform: HTML5 (itch.io), portrait, touch first
	•	Status: in development
