# Sprite inventory

Source: Kenney Top-down Shooter, CC0. Files are under `assets/graphs/kenney/`.

## Player

- `assets/graphs/kenney/PNG/Survivor 1/survivor1_stand.png` — standing survivor.
- `assets/graphs/kenney/PNG/Survivor 1/survivor1_gun.png` — survivor holding a pistol.
- `assets/graphs/kenney/PNG/Survivor 1/survivor1_machine.png` — survivor holding a machine gun.
- `assets/graphs/kenney/PNG/Survivor 1/survivor1_reload.png` — survivor reloading.

## Zombie

- `assets/graphs/kenney/PNG/Zombie 1/zoimbie1_stand.png` — standing zombie.
- `assets/graphs/kenney/PNG/Zombie 1/zoimbie1_gun.png` — zombie holding a pistol.
- `assets/graphs/kenney/PNG/Zombie 1/zoimbie1_machine.png` — zombie holding a machine gun.
- `assets/graphs/kenney/PNG/Zombie 1/zoimbie1_reload.png` — zombie reloading.

The pack contains one zombie character set. Variants such as runners, tanks, and
the boss can be derived later by tinting, scaling, or flipping this sprite in code.

## Bullets and weapons

There is no standalone bullet or projectile sprite in this pack. Weapon art is
available at `assets/graphs/kenney/PNG/weapon_gun.png`,
`assets/graphs/kenney/PNG/weapon_machine.png`, and
`assets/graphs/kenney/PNG/weapon_silencer.png`. A projectile visual will need to
be derived from an existing sprite in code; do not add new artwork.
